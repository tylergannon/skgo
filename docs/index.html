Write each part in its natural language.

skgo is an ordinary SvelteKit adapter on one side and ordinary Go on the other. Code generation connects them without asking either community to pretend.

web/src/routes/+page.svelte

The Svelte side

<script lang="ts">
  import { addTodo, todos }
    from './todos.remote';
</script>

{#each await todos() as todo}
  <p>{todo.text}</p>
{/each}

Components, routing, navigation, boundaries, and Kit's native remote-function client stay SvelteKit.

web/src/routes/todos.remote.go

The Go side

func todos(context.Context) ([]Todo, error) {
  return store.List(), nil
}

func addTodo(ctx context.Context, text string) (Todo, error) {
  todo := store.Add(text)
  return todo, skgo.RefreshRequestedNoArg(ctx, todos)
}

var _ = skgo.Query(todos)

Application I/O, trust, state, errors, loads, and HTTP handlers stay Go.

go generate

emits Kit-facing stubs, TypeScript types, strict wire codecs, route links, and Go registration

Not just remote functions

A Go monolith with a real frontend framework.

01

Remote functions

Typed queries, commands, forms, live queries, and batched queries use Kit's own browser protocol.

02

Server loads

Colocated Go functions answer layout and page data, including streamed promises and nested errors.

03

HTTP routes

A +server.ts route is implemented beside it as a normal net/http handler.

04

In-process SSR

Kit's renderer runs inside embedded goja. Pages leave Go with their markup already present.

05

Kit behavior

Route params, CSR-only pages, scriptless pages, hooks, transport, errors, redirects, and CSP keep Kit semantics.

06

A Go deployment

Frontend assets and the SSR bundle are embedded. Node is needed to build, never to run.

Five minutes to the useful part

Generate the plumbing.
Own the application.

The starter contains a query, command, generated types, server composition, dev proxy, embedded production build, and one shared origin setting. Choose mise, Just, or plain shell scripts for its build entry point.

  1. Createskgo new writes a standalone Go module and SvelteKit app.
  2. BuildThe selected mise, Just, or shell command installs, generates, builds, and links.
  3. ExtendAdd Go beside the route; consume the generated module from Svelte.
