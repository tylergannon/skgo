# junkyard Go fixture module: `internal/remotegen/testdata/mod`

Source root: `junkyard/go/internal/remotegen/testdata/mod/` — a complete, committed example of authored input and generated output for the Stage A generator (module `example.com/fix`, `go 1.27`).

## Purpose

Shows exactly what a developer writes (`*.remote.go` + a `//go:build jsonschema` registration file) and exactly what the generator and go-gen-jsonschema emit (`.remote.ts`, `types.ts`, `jsonschema/*.json`, `jsonschema_gen.go`, `.skgo/remotes-source.json`). Two layouts are covered: a package inside the app tree (`app/src/lib/documents`) and a package outside it redirected into `src/routes` by directive (`remotes/messages`).

## Key concepts

### Authored input

- **A `.remote.go` file is an ordinary Go package** with named input/output structs and package-level wrapper vars — `junkyard/go/internal/remotegen/testdata/mod/app/src/lib/documents/document.remote.go:L1-L35`:

  ```go
  var GetDocument = remote.Query("getDocument", getDocument)
  var SaveDocument = remote.Command("saveDocument", saveDocument, remote.CommandOptions{
      RefreshRequested: []remote.QueryRef{GetDocument.Ref()},
  })
  var WatchDocument = remote.Live("watchDocument", watchDocument)

  func getDocument(context.Context, GetDocumentInput) (Document, error) { ... }
  func saveDocument(context.Context, SaveDocumentInput) (Document, error) { ... }
  func watchDocument(context.Context, GetDocumentInput, func(Document) error) error { ... }
  ```
  Type params `In`/`Out` are inferred from the handler signature; the generator reads them from the instantiated wrapper type (`remotegen.md`).

- **The schema registration file** is `//go:build jsonschema`-tagged so it compiles only for the provider: stub `Schema()` methods that panic, plus `var _ = jsonschema.NewJSONSchemaMethod(T.Schema)` per root type — `junkyard/go/internal/remotegen/testdata/mod/app/src/lib/documents/schema.go:L1-L19`. The generator only *reads* this file to learn which types are registered.
- **Redirect directive**: `//skgo:remote output=src/routes/remotes/messages/data.remote.ts` as the first line (before `package`) places the stub of a non-app package into the route tree — `junkyard/go/internal/remotegen/testdata/mod/remotes/messages/messages.remote.go:L1-L21`.
- **`go.mod` shape**: requires `go-gen-jsonschema v1.0.0-rc.5`, `santhosh-tekuri/jsonschema/v6` (runtime validation dep of the generated Go), the adapter via relative `replace`, and declares the provider with a `tool` directive — `junkyard/go/internal/remotegen/testdata/mod/go.mod:L1-L22`.

### Generated `.remote.ts` (verbatim)

`junkyard/go/internal/remotegen/testdata/mod/app/src/lib/documents/document.remote.ts:L1-L22`:

```ts
// Code generated by skgo remotes generate. DO NOT EDIT.
// skgo:module source=app/src/lib/documents/document.remote.go package=example.com/fix/app/src/lib/documents

import { command, query } from '$app/server';
import type { Document, GetDocumentInput, SaveDocumentInput } from '../skgo/types/example.com~fix~app~src~lib~documents/types';

export type { Document, GetDocumentInput, SaveDocumentInput };

function goRemoteOnly(name: string): never {
	throw new Error(`Go remote ${name} was invoked by the Node backend`);
}

export const getDocument = query('unchecked',
	(_input: GetDocumentInput): Document => goRemoteOnly('getDocument'));

export const saveDocument = command('unchecked',
	(_input: SaveDocumentInput): Document => goRemoteOnly('saveDocument'));

export const watchDocument = query.live('unchecked',
	async function* (_input: GetDocumentInput): AsyncGenerator<Document, void, void> {
		goRemoteOnly('watchDocument');
	});
```

The redirected module's stub imports through a longer relative path (`'../../../lib/skgo/types/example.com~fix~remotes~messages/types'`) — `junkyard/go/internal/remotegen/testdata/mod/app/src/routes/remotes/messages/data.remote.ts:L1-L14`.

### Generated types and schemas (go-gen-jsonschema output)

- `types.ts` per package, header `// Code generated by go-gen-jsonschema. DO NOT EDIT.`, one `export type X = { "field": type; }` per registered root — `junkyard/go/internal/remotegen/testdata/mod/app/src/lib/skgo/types/example.com~fix~app~src~lib~documents/types.ts:L1-L15`; slices render as `Array<string>` — `.../example.com~fix~remotes~messages/types.ts:L8`.
- `jsonschema/<Type>.json`: `{"type":"object","properties":{...},"required":[all fields],"additionalProperties":false}` plus a `.json.sum` digest file — `junkyard/go/internal/remotegen/testdata/mod/app/src/lib/documents/jsonschema/Document.json:L1-L5`, `Document.json.sum:L1`.
- **`jsonschema_gen.go`** (`//go:build !jsonschema`) embeds the `jsonschema/` dir, compiles each schema once in `init()` with `santhosh-tekuri/jsonschema/v6`, and provides `Schema() json.RawMessage` and `ValidateJSON([]byte) error` per type — `junkyard/go/internal/remotegen/testdata/mod/app/src/lib/documents/jsonschema_gen.go:L1-L118`. `ValidateJSON` is the hook the runtime's `decodeTypedArg` calls (`remote-runtime.md`).

## Gotchas

- The committed `remotes-source.json` here has **no `digests` map** (older inventory version); real runs write it (`generate.go:L197-L211`). Tests that copy the fixture delete `app/.skgo` first because the copy's layout differs (`route_test.go:L36-L43`).
- The fixture `go.mod` `replace ... => ../../../..` is relative to the repo; copying the fixture elsewhere requires `absolutizeReplaces` (`route_test.go:L26-L33`).
- Generated `jsonschema_gen.go` pulls `santhosh-tekuri/jsonschema/v6` into the *app's* runtime binary — a real dependency cost of validate-at-runtime.
- Handler stubs return zero values (`return Document{}, nil`); the fixture exists only for type-checking and generation, not behaviour.
- `types.ts` quotes property names (`"id": string;`), which is valid TS but unusual; downstream tooling should not assume bare identifiers.
