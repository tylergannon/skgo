## Raw pnpm map amendment

The original native get/merge/set assumption was disproved: pnpm 12.9.1 normalizes relative patch values to absolute paths, while `config set` does not support updating only a property path. The bounded read-only `gopkg.in/yaml.v3 v3.0.1` addition is justified by that concrete preservation requirement, not a general library preference.

`internal/kitpatch/kitpatch.go:526–613` now decodes one document, requires EOF, preserves default duplicate detection, validates the patch map's literal string keys/values through generic values, and delegates alias/merge/flow/quoted syntax to the parser. It compares raw key sets and resolved paths with actual native configuration before any writes; ambiguous global/environment/source results refuse. It merges the owned portable relative value into the raw map, then uses native pnpm as sole writer. Unrelated relative and absolute values are therefore preserved logically instead of being replaced by their normalized getter output. No hand-written YAML scanner, YAML emitter or lockfile writer was added.
