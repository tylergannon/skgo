  side marks other-language counterparts as `obsolete`, but only when they pass
  publication's own ownership test (`generatedArtifact`, the
  `// Code generated by` header). The `readdirSync` overlay filters those
  entries, handling both string and Dirent results. Nothing is deleted before
  the invocation succeeds. An authored counterpart stays visible, so it is
  still a Kit conflict.
- `internal/gen/layout_params_test.go`: the new
  `TestStage2LayoutMetadataAcrossLanguageSwitches` installs the real
  `example/e2e/fixtures/go-dev-added` files. It cycles TS→JS→TS, running
  Check→Run→Check each time, and asserts that no stale owned stubs remain. At
  each step it serves the added route's `__data.json` and requires the literal
  `New Go route revision one`. Finally, it requires that an authored
  `+page.server.js` beside a generated `.ts` page still fails with
  `route_duplicate_files` in both Check and Run, and that the authored file is
  left unchanged.
- `example/e2e/fixtures/go-dev-added/page.server.go.txt` and
  `internal/adapter/prerender_inputs_lifecycle_test.go` now use
  `PageRequestEvent`.
- Worklog: the false hook/load tracking claim is withdrawn, and the stage-3
  expansion based on it is explicitly rescinded.
