# Native development request bridge

decision: Preserve the application's actual constructor, FetchConfig, registry configuration and Go hooks through an explicit NativeDevelopment fs.FS carrier. Rebuilding a fresh generated boundary loses app-owned options.
friction: A bidirectional HTTP response relay deadlocks under net/http's normal request-body drain before header flush -> enable full duplex for the private streamed /response endpoint.
decision: Logical request handles live in the original process map and are cryptographically random; replacement rejects unknown handles instead of replaying callbacks. Callback disconnect cancels its own request, never the dev service.
friction: Minimal native callback fixtures had no endpoint manifest and hid two joined failures: begin rebuilt an empty endpoint registry against the full manifest, and callbacks retained the skip-dispatch continuation marker. Native begin must traverse the actual configured app and callback contexts must clear only the transport continuation marker.
friction: Native Go-origin fetches cannot enter the old Go page/data dispatcher: it has no Kit renderer and its data node identities are not the live Kit graph. Route the existing credential-aware fetch continuation over vite.sock before application middleware so Kit owns dispatch and starts one fresh Go boundary.
friction: Native lowering preserved registered function identity only for Refresh-prefixed SDK calls; ReconnectRequestedNoArg received a revision-body pointer and sign-in failed after writing its cookie. Preserve the exact current SDK identity-taking API set, including Requested, IgnoreRequested and ReconnectRequested.
friction: Kit3 matcher parameters contain converted values (for example number42), not necessarily strings. Native callbacks must use the original logical URL and current route pattern with Go's existing matchers; serializing Kit's typed params into a second schema loses raw values and Go matcher types.
decision: The reserved configured remote prefix retains its Go wire owner for native internal fetches, matching public routing; Kit's dev remote map only contains modules already transformed, so unimported prerender remote URLs cannot be used as an alternate remote registry.
