decision: Generated Go overlays evolve between locals, matcher, hook, discovery, and projection phases. Existing on-disk bindings are not interchangeable with these intermediate source views. Package snapshots must compare relevant source/configuration before reuse; callers can instead inspect generate.Prepare's discovery graph before generate.Prepared.Run.

An IllTyped supplied root is not reusable: decline it and preserve ordinary loading/diagnostics rather than making optional reuse break a previously successful generation.
