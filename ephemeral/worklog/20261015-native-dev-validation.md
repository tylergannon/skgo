# Native dev validation

- `kit-patch` defaulted to ambient pnpm, and its Go config fixtures did the same; this broke outside `vp exec` when ambient pnpm differed from the declared supported pin. Route the command and fixtures through VitePlus's managed package-manager environment; focused CLI and all kitpatch tests now pass.
- While adapter source is being edited in a shared worktree, `go run skgo dev` can embed one fingerprint then see a newer live linked adapter at startup. Start actual-app qualification after the adapter owner announces a stable checkpoint; do not suppress the identity check.
- A real HTTP proxy response must be checked with `Header.Values`: stamping mode in both the outer ResponseWriter and ReverseProxy ModifyResponse emitted two `X-Skgo-Mode: dev` lines; browser Fetch joined them as `dev, dev`. Stamp local errors locally and proxy responses in ModifyResponse. The real UDS router regression asserts exactly one value on both paths.
- The first native query callback accessed Kit's guarded `event.url`; generated queries failed with `remote_request_property` although the page shell rendered. The real Home screenshot showed two Internal Error boundaries. Request-owner metadata must avoid restricted query event properties.
