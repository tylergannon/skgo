decision: The generated server template always calls `generated.Actions()`, including when a fresh demo declares no page actions. Emit an empty action registry in that case, as the other generated registry functions do; the existing `skgo.NewActions()` accepts an empty list, and pinned Kit treats pages without actions as having no action handler.
finding: VitePlus 0.3.3 installed pnpm 12.6.0 inside both fresh apps. Passing `--allow-build=esbuild` as one argument let the upstream Storybook installer finish; the prior separate-argument form failed in hosted cycle 36449678439.
friction: A new worktree has no `example/web/build` assets, so `just test` fails its real-handler tests until `just install` and `just build` have run. That is a setup precondition, not a product regression.
