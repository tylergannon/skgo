decision: Kit's pinned client reruns a server node when its recorded params, search parameters or dependencies changed and sends one invalidated-node mask; the account fixture uses separate page and layout serials to expose both sides.
friction: A visible unchanged layout serial can hide an unintended layout execution if Kit skips the returned node -> require a later refreshAll with literal serials to expose hidden runs.
friction: A no-rerun assertion can pass if the browser ignored the navigation entirely -> assert the literal destination URL before asserting the cached serial.
