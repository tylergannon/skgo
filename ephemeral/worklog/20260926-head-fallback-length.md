decision: Kit 3 next.28 cancels a synthesized HEAD response body before its Node response writer sees it; net/http instead infers Content-Length from writes on HEAD. Suppress writes only for HEAD resolved to GET, while forwarding headers, status and Flush. Do not add raw connection interfaces absent from Kit's Response endpoint contract.
friction: A fresh worktree lacks the example app's node_modules and built manifest, so `just test` fails on example fixtures until `just install` and `just build` run. The initial focused real-server test isolated the endpoint regression before that setup.
