# Swift buffer boundary

correction: The user requires a simple buffer ABI: Swift owns HTTP; Zig owns protocol, keys and cache. Removed the provisional graph/token API completely. Three C exports now exchange owned byte buffers without cross-language value handles.
decision: Finite-model JSON is the local ABI buffer representation, while Kit's remote wire remains devalue. An empty C argument means omitted; Swift uses nil and rejects explicitly supplied empty Data. Unsupported non-JSON values fail rather than being coerced. This requires no Go JSON projection.
friction: Cancellation while awaiting a transport Task's value does not return promptly if that transport ignores cancellation. The actor now owns continuations keyed by call ID; cancellation/shutdown complete them immediately and discard late transport responses.
friction: Zig 0.17 standalone fetch without --save computes the correct archive hash but recompresses a global-cache archive containing an extra repository root. A later cold build reads it as a naked package and reports N-V hash mismatch. Pinned compiler Maker/Fetch.zig runResource sets package_root to tmp_directory_path when local_storage is absent, unlike the root-aware local-storage path. A truly empty global cache built the published dependency correctly. Removed the one malformed cached tarball; use the existing documented fetch --save command when adding a dependency instead of changing the package pin. --pkg-dir alone has no effect without --save; Maker.zig only creates local_storage in the save branches. A fresh --save fetch produced a correctly rooted global archive, and a consumer rebuilt its dependency from that archive after deleting its local package cache.
friction: Swift 6 treats nested Data.withUnsafeBytes closures inside an actor method as nonisolated and rejects captured OpaquePointer handles. The replacement buffer implementation uses synchronous file-level bridge functions and creates no graph handles in Swift.

friction: SwiftPM rejects remote dependencies containing unsafe linker flags. The command-line package currently locates the local Zig archive through such a flag; milestone 6 must supply the target libraries through its generated Apple build configuration or an XCFramework instead of publishing this manifest unchanged as a remote SwiftPM dependency.
