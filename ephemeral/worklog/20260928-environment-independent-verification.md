# Environment independent verification

finding: A working typed dev page and a token-protected module endpoint did not prove private-value exclusion. On the live fixture, ordinary Vite serving and the Go proxy exposed static private values through `/.svelte-kit/generated/dev/env/private/server.js?raw`, generated build private modules, generated dev config, and `/.svelte-kit/output/server/chunks/config.js?raw`. Probe the actual generated paths and raw variants; the original deny patterns missed Kit's build/dev directory layer. Reported to the adapter implementer before merge.
friction: The available node_repl Playwright imports fail on a missing default export, while cached Playwright through Node works. A cached Playwright version requested absent Chromium 1223; using the installed Chromium 1243 executable enabled independent DOM-based browser checks without installing packages or creating screenshots.
finding: After resolved-path protection blocked 228 ordinary/raw/import/fs/id/encoded requests, case variants `/.SVELTE-KIT/...` and `.../ENV/private/server.js?raw` still exposed the private static value on macOS. Filesystem case behavior belongs in the path boundary, not only lexical URL comparisons. Reported before merge; retain those paths in the regression.
