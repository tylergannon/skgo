# 114: Example: bound completed async SSR probe groups

https://github.com/tylergannon/skgo/issues/114

The new `/async-ssr` example demonstrates three-way overlap and live-query hydration. It remembers completed overlap groups so the browser live subscription can reconnect alone after the ordinary queries have hydrated from cached results.

That completed-group map currently retains each unique group for the lifetime of the example process. Add bounded expiry or another bounded lifecycle that preserves the live reconnect behavior. Verify fresh groups still require all three Go operations to start before any returns, and that the mixed page remains correct after its live subscription reconnects. This is example-fixture cleanup, not an SSR runtime leak.

Follow-up to #110; intentionally deferred to keep the working concurrency change focused.
