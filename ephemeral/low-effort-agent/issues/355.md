# 355: Asset URLs omit paths.base when paths.relative is false and paths.assets is unset

https://github.com/tylergannon/skgo/issues/355

At v0.36.0 (`3b382953`, which is also current `main`), an app with `paths.base` set, `paths.relative: false` and no `paths.assets` gets client asset URLs without the base.

**Kit (3.1.0):** `assets` defaults to the base. `src/runtime/app/paths/internal/server.js` has `export let assets = __SVELTEKIT_PATHS_ASSETS__ || base;`, and `page/render.js` starts from `let assets = paths.assets` and builds each URL with `client_path(path, { base, assets })`, i.e. `${assets}/${path}`.

**skgo:** the adapter copies `builder.config.paths.assets` into the manifest unchanged, so it is empty when unset ([internal/adapter/skgo-adapter.js:608-609](https://github.com/tylergannon/skgo/blob/3b382953fb97f77aecd1f5122d76dfbe586fec89/internal/adapter/skgo-adapter.js#L608-L609)). [document_assemble.go:31-63](https://github.com/tylergannon/skgo/blob/3b382953fb97f77aecd1f5122d76dfbe586fec89/document_assemble.go#L31-L63) falls back only when `Relative` is set:

```go
assets := s.info.Assets
if s.info.Relative {
	...
	if assets == "" {
		assets = base
	}
}
prefixed := func(path string) string {
	if strings.HasPrefix(path, "/") {
		return s.base + path
	}
	return assets + "/" + path
}
```

With `base: '/app'`, `relative: false` and `assets` unset, `prefixed("_app/immutable/entry/start.js")` returns `/_app/immutable/entry/start.js` where Kit writes `/app/_app/immutable/entry/start.js`. The static handler serves immutable files under `base + "/" + appDir + "/immutable/"` ([static.go:371](https://github.com/tylergannon/skgo/blob/3b382953fb97f77aecd1f5122d76dfbe586fec89/static.go#L371)), so the stylesheets, modulepreloads and the start/app imports in the boot script would all 404. The page renders on the server but never hydrates.

The only assemble test with a base sets `s.info.Relative = true` ([document_assemble_test.go:19-20](https://github.com/tylergannon/skgo/blob/3b382953fb97f77aecd1f5122d76dfbe586fec89/document_assemble_test.go#L19-L20)), so this branch is untested. I confirmed this by reading the code. I have not run a built app with this configuration.

**Expected:** apply Kit's default (`assets = Assets || base`) whatever `Relative` is. Add a test with `base: "/app"`, `Relative: false` and `Assets: ""` that checks for literal `/app/_app/immutable/...` URLs in the stylesheet links, the modulepreloads and the boot script.
