# 273: Add real-build regression coverage for Go hook refusals through Kit

https://github.com/tylergannon/skgo/issues/273

Stage-4 Go tests cover the /begin refusal response, but committed real-build fixtures do not independently protect the JavaScript mapping to Kit Redirect/HttpError classes.

Opus manually ran a real-build probe: a hook refusing an internal fetch produced literal 418 JSON {"status":418,"message":"teapot literal"} and redirect status307, matching Kit. The behavior works; this is missing regression coverage.

Add equivalent assertions within the existing prerender production fixture: refusal happens before Go load execution, and rendered output confirms the actual error status/body and redirect. Removing the bridge's Redirect/HttpError handling must fail the test. Reuse one build instead of adding a separate expensive suite. Nonblocking RequestEvent follow-up.
