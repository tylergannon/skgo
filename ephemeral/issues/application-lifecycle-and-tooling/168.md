# #168: Define a Go equivalent for Kit server init

https://github.com/tylergannon/skgo/issues/168
State: open

## Issue body

## Desired result

A skgo application should have a startup point that gives developers Kit’s server `init` lifecycle semantics without running application I/O in JavaScript.

## Acceptance

A startup fixture runs at the intended lifecycle point in development and production, and a failing initialization prevents serving with a clear error.

## Current boundary

The matrix has no Go server `init` equivalent.

Feature matrix: https://tylergannon.github.io/skgo/features.html. Kit’s pinned source and client behavior define compatibility.
