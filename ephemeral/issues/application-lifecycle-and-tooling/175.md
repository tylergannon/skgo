# #175: Ship unified skgo checking, linting, formatting, and fixes

https://github.com/tylergannon/skgo/issues/175
State: open

## Issue body

## Desired result

A developer should have one skgo command for Go, Svelte, TypeScript, generated bindings, lint, and formatting diagnostics, with a deliberate fix mode.

## Acceptance

A fresh generated app can run the command; deliberate authored errors are reported with useful locations; fix mode changes only applicable files and rechecks; missing tooling cannot yield a clean result.

## Current boundary

The example has a separate `svelte-check` script, while integrated checking and fixes are WIP in the agent-tooling task.

Feature matrix: https://tylergannon.github.io/skgo/features.html. Kit’s pinned source and client behavior define compatibility.
