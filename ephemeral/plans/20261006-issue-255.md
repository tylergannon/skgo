# Issue #255: restore the shared prerender load fixture

Planning only. No implementation is authorized in this session.

## Desired result

The seven existing generator tests that consume `loadSource` reach their
existing assertions with a fixture that conforms to the current typed Go load
API. The generator, runtime, and browser behavior remain unchanged.

## Verified basis

- Baseline: `origin/main` at `10ad4dea4765245eafa67b987799afcca3876449`.
- [Issue #255](https://github.com/tylergannon/skgo/issues/255) identifies the
  integration regression. `git diff f0631f0 d034f77 --
  internal/gen/prerender_test.go` confirms that merge #252 replaced
  `func site(RequestEvent)` with `func site(context.Context)` and restored its
  `context` import. The obsolete signature remains on the baseline.
- `load.go` requires `func(skgo.RequestEvent[P]) (Out, error)`.
  `internal/gen/load_params.go` generates the route-local alias
  `type RequestEvent = skgo.RequestEvent[RouteParams]` before loading the
  application. The stand-in API in `internal/gen/ownership_test.go` enforces
  the same typed signature.
- SvelteKit source is the worktree's frozen-lockfile installation, verified as
  `@sveltejs/kit` 3.0.0. `src/runtime/server/page/load_data.js` calls server
  loads with an event object; its `src/utils/routing.js` supplies the route
  parser used by these generator fixtures. No mirrored Kit behavior needs a
  new design for this repair.
- Completed [main CI](https://github.com/tylergannon/skgo/actions/runs/37528973842)
  reports this exact type mismatch for all seven consumers, including the six
  inheritance subtests. In [release qualification](https://github.com/tylergannon/skgo/actions/runs/37528974564),
  dev BDD passed, while prod failed at Go tests and skipped its browser suite.
  These results establish the current failure, not a successful repair.

## Repair boundary

Restore the shared `loadSource` constant in `internal/gen/prerender_test.go`
to `func site(RequestEvent) (Data, error)` and remove its obsolete `context`
import. Keep its literal `"hello"` result and `skgo.Load(site)` declaration.
The eventual implementer owns this fixture repair only. Do not weaken the
typed marker or the fixture stand-in, delete tests, change assertions or
timeouts, redesign the harness, or add browser scenarios for a fixture-only
compile regression.
Use a `test:` Conventional Commit PR title, matching the fixture-only scope;
`fix:` would make a qualified merge eligible for an automatic patch release.
