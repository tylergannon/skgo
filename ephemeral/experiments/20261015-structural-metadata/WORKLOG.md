decision: Kit dev's route watcher owns metadata recreation and replacement inside Kit closures; its public generated client module and `$app/manifest` do not expose the full route patterns/node branch metadata Go needs. The adapter's full build has complete builder.manifest and can publish a coherent Go build after Go generation.
friction: an isolated copy of example/web cannot build the adapter's Go prerender package until it is nested under a copied Go app root; when copying, preserve the app module and use GOWORK=off plus the local module replacement. Do not copy only web/ and assume the adapter's relative Go package path resolves.
