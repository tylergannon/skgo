Each rule `skgo check` and `go vet` enforce has a code, a consequence, a repair and an example. This prints them, for a person or an agent that hit one.

## Usage

`skgo advice --help` prints:

```text
Usage of advice:
  -json
    	write structured JSON guidance
```
