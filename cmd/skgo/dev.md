One listener serves the Go application with hot reload and Vite's dev server. A compatible Go edit installs into the running application; other Go changes, and edits the native loader fails to install, rebuild and replace it. Edits to Svelte files reach the browser through Vite as usual. See [Development server](/docs/skgo/development-server).

## Usage

```text skgo dev -h
```
